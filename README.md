# 🏠 МедиаХаус

Симулятор оценки недвижимости. Угадайте стоимость дома по фотографии и описанию.

## Описание

Интерактивное веб-приложение, где пользователь оценивает стоимость объектов недвижимости. За 10 раундов нужно угадать цену каждого объекта с помощью бегунка. Система подсчёта баллов учитывает точность оценки.

## Механика

- **10 раундов** — каждый раунд показывает случайное объявление
- **Бегунок** — пользователь двигает ползунок для выбора цены
- **Система баллов** — от 0 до 10 за каждый раунд (максимум 100):
  - ≤5% отклонение → 10 баллов
  - ≤10% → 9 баллов
  - ≤15% → 8 баллов
  - ≤20% → 7 баллов
  - ≤30% → 5 баллов
  - ≤50% → 3 балла
  - ≤75% → 1 балл
  - >75% → 0 баллов

## Результаты

| Баллы | Результат | Описание |
|-------|-----------|----------|
| 70-100 | 🎯 Опытный инвестор | Близок к результату |
| <70, завышение | 💰 Щедрый инвестор | Переплачивает за недвижимость |
| <70, занижение | 🪙 Скряга | Экономный инвестор |

## Технологии

- React 18 + TypeScript

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## Деплой

### Static hosting (Vercel, Netlify, GitHub Pages)

1. Соберите проект: `npm run build`
2. Загрузите содержимое `dist/` на хостинг
3. Настройте SPA fallback на `index.html`

### Docker

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

## Данные

Данные объявлений получены из открытых источников (ЦИАН). Каждое объявление содержит:
- Фотографию
- Описание (площадь, участок)
- Локацию
- Реальную цену
